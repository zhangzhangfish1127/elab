## 🌟 项目简介 / Introduction

**中文**：这是一个专为初中科学课程设计的动态绘图工具集。将课本上的抽象概念，变成能拖拽、能实时反馈的动态画面，方便教师在课堂上演示，也方便学生课后自主探究。

**English**: This is a dynamic drawing tool set designed for middle school science courses. It turns abstract concepts from textbooks into draggable, real-time dynamic images, making it convenient for teachers to demonstrate in class and for students to explore independently after class.

## 🛠 技术说明 / Tech Stack

*   **纯前端实现 / Pure Frontend**: 使用原生 HTML5 + CSS3 + Vanilla JavaScript。
*   **无依赖 / No Dependencies**: 无需安装 Node.js，无需打包工具，直接运行。
*   **部署 / Deployment**: 托管于 Cloudflare Pages。
*   **无障碍 / Accessibility**: 内置色觉障碍（色盲）适配模式 / Built-in color blindness adaptation mode.
