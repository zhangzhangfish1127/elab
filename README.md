## 🌟 项目简介 / Introduction

**中文**：`ijhub`（Junior Interactive Hub）是一个纯前端的初中全科动态交互平台。我们把课本上枯燥的图表、实验和抽象概念，变成了可以拖拽、有实时反馈的动态模型，让学习和教学变得直观且有趣。

**English**: `ijhub` is a pure frontend interactive platform for middle school students. We turn abstract concepts, charts, and experiments from textbooks into draggable, real-time dynamic models, making learning and teaching intuitive and engaging.

## 🛠 技术特性 / Tech Stack

*   **纯前端实现 / Pure Frontend**: 原生 HTML5 Canvas + JavaScript 开发，无任何第三方框架依赖。
*   **全局搜索 / Global Search**: 内置毫秒级全学科关键字搜索。
*   **无障碍 / Accessibility**: 内置色觉障碍（色盲）适配模式，保护视力与无障碍体验。
*   **响应式设计 / Responsive**: 完美适配 iPad、平板及电脑端。
